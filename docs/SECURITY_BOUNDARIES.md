# SECURITY_BOUNDARIES

文隐 V1 是纯前端本地工具，不包含后端密钥份额、数据库、登录或云同步。

## 明确边界

- 不保存密钥：密钥不得写入 localStorage、IndexedDB、Cookie、URL 或日志。
- 忘记密钥无法恢复：没有后端找回机制。
- 密钥只输入一次：中文、英文、数字和符号都可以作为密钥，常见古诗或名句可以使用，但不建议作为极高安全密钥。
- 弱密钥会降低整体安全性：标准模式允许弱密钥但应提示风险，极高安全模式要求密钥强度达到 4/4。
- 自然中文层不是安全边界：安全性来自 Argon2id 与 XChaCha20-Poly1305。
- 时间锁使用本地设备时间：它是减少误开的轻量约束，不是强安全边界。
- 时间锁可能被绕过：改设备时间、改代码或运行旧版本都可能绕过时间锁，真正安全仍依赖强密钥和加密算法。
- 本地失败冷却不能防离线撞库：它只约束当前设备和当前浏览器。
- 蜜罐假明文不是严格 Honey Encryption：它是极高安全模式下的工程增强，不替代强密钥和高成本 KDF。
- 蜜罐模式下页面不应通过状态文案、括号编码或调试信息区分真假结果。用户需要通过双方事先约定的识别语、暗号或上下文细节确认真明文。

## 网络请求

文隐不需要后端服务。不得发送原文、密钥、密文、payload、解密结果或任何用户输入。

## 密钥复制

界面允许用户主动复制密钥，但不会自动把密钥和密文合并发送，也不会保存密钥。用户应通过可信渠道单独传递密钥。
