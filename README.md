# 文隐 WenYin / ChiCrypt

文隐是一个纯前端、本地优先的中文自然密文加密网页应用。用户输入原文、密钥、安全等级和伪装风格后，浏览器本地使用 Argon2id 与 XChaCha20-Poly1305 完成认证加密，再把 payload 编码成看起来比较通顺的中文段落。

## 本地运行

```bash
npm install
npm run dev
```

Vite 默认本地地址通常是：

```bash
http://localhost:5173/
```

## 构建与验证

封版前必须执行：

```bash
npm run validate:dictionaries
npm test
npm run typecheck
npm run lint
npm run build
```

构建后可将 `dist/` 目录作为纯静态资源部署。项目不需要后端服务器、数据库、登录系统或 Docker。

## 使用方法

1. 在“加密”页输入原文。
2. 手动输入密钥，或点击“生成强密钥”自动填入 4 级强度密钥。
3. 选择安全等级、伪装风格和长度模式。时间锁与蜜罐假明文在“高级选项”中设置。
4. 点击“生成中文密文”，完整复制生成的中文密文。
5. 单独复制密钥并通过可信渠道告知接收方。
6. 接收方在“解密”页粘贴中文密文并输入相同密钥。

## 安全等级

- 标准：适合日常内容，加密和解密更快。弱密钥会显示风险提示，但不会阻止生成密文。
- 极高安全：适合重要内容，加密和解密更慢，必须使用强度 4/4 的密钥。

## 伪装风格

伪装风格只影响中文密文外观，不影响底层加密算法。当前支持日常风、聊天风、小说风和古文风。每种风格使用独立短语级词库、模板和过滤规则，并按当前选择动态加载。

Cover Text 是 payload 的中文外壳，不是安全边界。当前默认使用紧凑模式，优先缩短中文密文；平衡模式会保留更强文学感但更长。一个编码单元可以包含一个或多个中文句子，但必须整体可被 decoder 还原。不能手动润色、增删字词、改标点或改变词组内部空格。

## 安全说明

所有处理都在浏览器本地完成。密钥、原文、密文 payload 和解密结果不会上传服务器。

忘记密钥无法恢复。自然中文层只是密文外壳，不提供额外密码学安全性。时间锁使用本地设备时间，是轻量约束，不是强制销毁；改设备时间、改代码或运行旧版本可能绕过时间锁。本地失败冷却只影响当前设备，不能阻止离线撞库。蜜罐假明文不是严格密码学意义上的 Honey Encryption，也不替代强密钥。

## 词表发布纪律

`coverVersion` 对应的模板和词表一经公开发布，不应修改、删除或重排。若要扩展词表或调整模板，应新增版本并保留旧版本解码能力。

当前封版前按新项目处理，新生成密文使用 `coverVersion = 2`；正式发布后必须遵守版本冻结规则。

## 常见问题

**中文可以做密钥吗？** 可以。中文、英文、数字、符号都可以作为密钥。密钥会先 trim 首尾空白并做 Unicode NFKC 规范化，再进入 KDF。

**为什么短文本密文仍比原文长很多？** 密文需要包含 salt、nonce、认证 tag、payload header、时间策略和自然中文编码开销，短文本会被固定开销放大。

**能调整中文密文长度吗？** 可以。默认“紧凑”优先缩短密文；“平衡”更像自然段落但更长。长文本会在加密前自动尝试压缩，只有确实变短才启用。

**蜜罐模式下如何确认真明文？** 页面不会告诉你结果真假。发送方应在真实原文里放入双方事先约定的识别语、暗号或只有双方知道的上下文细节。
