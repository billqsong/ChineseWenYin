# 文隐 WenYin / ChiCrypt

文隐（WenYin / ChiCrypt）是一个**纯前端、本地优先的中文自然密文加密项目**。

用户输入原文、密钥、安全等级和伪装风格后，浏览器会在本地使用 **Argon2id** 与 **XChaCha20-Poly1305** 完成认证加密，并把加密后的 payload 编码成一段看起来相对自然的中文文本。

> 简单理解：它不是把中文加密成乱码，而是把中文加密成另一段中文。

## 在线体验

👉 https://chinesewenyin.pages.dev

## 核心特点

- **中文到中文**：原文加密后仍表现为中文段落，而不是 Base64、乱码或二进制文本。
- **纯前端运行**：不需要后端服务器、数据库、登录系统或 Docker。
- **本地优先**：原文、密钥、密文 payload 和解密结果都在浏览器本地处理，不上传服务器。
- **认证加密**：底层使用 Argon2id 派生密钥，并使用 XChaCha20-Poly1305 完成认证加密。
- **多种伪装风格**：支持日常风、聊天风、小说风和古文风。
- **可解码中文外壳**：中文密文不是随机生成的装饰文本，而是可以被 decoder 还原为加密 payload 的自然中文编码层。
- **静态部署友好**：构建后只需要部署 `dist/` 静态资源目录。

## 适用场景

文隐更适合以下用途：

- 中文自然密文实验
- 中文文本伪装与隐写研究
- 前端密码学工程实践
- 本地优先隐私工具 Demo
- 开源中文加密项目学习与二次开发

不建议把它理解为“绝对安全通信工具”。真实高风险通信场景请使用成熟、经过长期审计的安全通信方案。

## 使用方法

### 加密

1. 打开“加密”页。
2. 输入需要加密的原文。
3. 手动输入密钥，或点击“生成强密钥”自动生成高强度密钥。
4. 选择安全等级、伪装风格和长度模式。
5. 如有需要，在“高级选项”中设置时间锁或蜜罐假明文。
6. 点击“生成中文密文”。
7. 完整复制生成的中文密文。
8. 单独复制密钥，并通过可信渠道告知接收方。

### 解密

1. 打开“解密”页。
2. 粘贴完整中文密文。
3. 输入与加密时相同的密钥。
4. 点击解密，查看还原后的原文。

## 安全等级

- **标准**：适合日常内容，加密和解密速度更快。弱密钥会显示风险提示，但不会阻止生成密文。
- **极高安全**：适合重要内容，加密和解密更慢，必须使用强度 4/4 的密钥。

## 伪装风格

伪装风格只影响中文密文的外观，不影响底层加密算法。

当前支持：

- 日常风
- 聊天风
- 小说风
- 古文风

每种风格使用独立的短语级词库、模板和过滤规则，并按当前选择动态加载。

## 中文密文说明

Cover Text 是 payload 的中文外壳，不是额外的安全边界。

当前默认使用**紧凑模式**，优先缩短中文密文；**平衡模式**会保留更强的自然段落感，但密文长度会更长。

一个编码单元可以包含一个或多个中文句子，但必须整体可被 decoder 还原。生成后的中文密文不能手动润色、增删字词、改标点或改变词组内部空格，否则可能导致解密失败。

## 安全说明

所有处理都在浏览器本地完成。密钥、原文、密文 payload 和解密结果不会上传服务器。

需要注意：

- 忘记密钥无法恢复原文。
- 自然中文层只是密文外壳，不提供额外密码学安全性。
- 时间锁使用本地设备时间，是轻量约束，不是强制销毁机制。
- 修改设备时间、修改代码或运行旧版本可能绕过时间锁。
- 本地失败冷却只影响当前设备，不能阻止离线撞库。
- 蜜罐假明文不是严格密码学意义上的 Honey Encryption，也不替代强密钥。

## 词表发布纪律

`coverVersion` 对应的模板和词表一经公开发布，不应修改、删除或重排。

如果需要扩展词表或调整模板，应新增版本，并保留旧版本解码能力。

当前封版前按新项目处理，新生成密文使用：

```text
coverVersion = 2
```

正式发布后必须遵守版本冻结规则。

## 常见问题

### 中文可以做密钥吗？

可以。中文、英文、数字、符号都可以作为密钥。密钥会先 trim 首尾空白并做 Unicode NFKC 规范化，再进入 KDF。

### 为什么短文本密文仍比原文长很多？

密文需要包含 salt、nonce、认证 tag、payload header、时间策略和自然中文编码开销。短文本会被固定开销放大，所以看起来会明显变长。

### 能调整中文密文长度吗？

可以。默认“紧凑”优先缩短密文；“平衡”更像自然段落但更长。长文本会在加密前自动尝试压缩，只有确实变短才启用。

### 蜜罐模式下如何确认真明文？

页面不会告诉你结果真假。发送方应在真实原文里放入双方事先约定的识别语、暗号或只有双方知道的上下文细节。

### 这个项目需要后端吗？

不需要。文隐是纯前端静态项目，构建后部署 `dist/` 即可。
